# 3GPP RAG

This project includes a demonstration local knowledge base for emergency and public-safety telecom contexts. It references sample 3GPP documents and labels them as demo knowledge rather than live standards data.

Example documents:

- 3GPP TS 22.179 - Mission Critical Push to Talk
- 3GPP TS 23.271 - Location Services
- 3GPP TS 23.501 - 5G architecture and slicing

The Copilot uses these documents as evidence when network and telecom questions are asked.
